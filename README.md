# Data Structures and Algorithms with C++

This repository contains my personal study and implementation of various **Data Structures and Algorithms** using **C++**. It is designed to help me understand the concepts more deeply and practice my coding skills.

## 🧠 Topics Covered

### 🔹 Data Structures
- Arrays
- Linked Lists (Singly, Doubly, Circular)
- Stacks (Array-based, Linked List-based)
- Queues (Circular Queue, Priority Queue)
- Trees (Binary Trees, Binary Search Trees, AVL Trees, Heaps)
- Hash Tables
  

### 🔹 Algorithms
- Sorting (Bubble, Selection, Insertion, Merge, Quick, Heap)
- Searching (Linear, Binary)
- Recursion & Backtracking
- Dynamic Programming
- Greedy Algorithms
